# Task 157: AI-Based Driver Drowsiness and Distraction Detection (In-Cabin Monitoring)

An AI-based computer vision system designed to monitor vehicle drivers in real-time. It detects fatigue, drowsiness, and distraction events (such as looking away, head tilt nodding, yawning, or cell phone usage) and maintains safety metrics, saving event video clips and incident logs.

This system leverages **MediaPipe Face Mesh** for high-precision, low-latency 3D facial landmark tracking (including Eye Aspect Ratio, Mouth Aspect Ratio, iris-based gaze tracking, and 3D head pose estimation) and **YOLOv8** for real-time cell phone detection to monitor distraction gestures.

---

## Key Features

1. **Facial Landmarks & Tracking**: Uses MediaPipe Face Mesh to capture 468 3D landmark points and 10 iris tracking points at high frame rates.
2. **Eye Aspect Ratio (EAR) & Yawning (MAR)**:
   - **EAR**: Computes average vertical/horizontal ratios of left and right eye contours to detect closed eyes (micro-sleeps).
   - **MAR**: Computes mouth height-to-width ratio of inner lip contours to identify yawn events.
3. **Head Pose Tilt Estimation**: Computes 3D head pose (Pitch, Yaw, Roll angles) using `cv2.solvePnP` against a canonical 3D face model, detecting nodding or head-turning distractions.
4. **Gaze Direction Tracker**: Measures iris offsets relative to eye boundaries to track when a driver is looking left, right, or center.
5. **Phone Usage Detection**: Integrates YOLOv8 to detect `cell phone` objects held by the driver, logging safety violations.
6. **Rolling Drowsiness Score**: Maintains a temporal fatigue score (0-100%) that rises when eyes are closed or yawning and decays when alert.
7. **Event Clip Buffering**: Implements a double-ended frame queue (deque) that records a 5-second video clip (3 seconds pre-event and 2 seconds post-event) of any critical distraction or micro-sleep trigger.
8. **Multi-Level Alerting & Evidence Snapshots**:
   - Generates Windows audio alarms using `winsound` (mild for warnings, high-pitch for critical alerts).
   - Draws glowing warning indicators and text HUDs on the frame.
   - Saves full-resolution JPG snapshots of the frames that triggered the alerts.
   - Compiles log records in `incident_log.csv` and summary metrics in `summary_stats.json`.
9. **Analytics Dashboard**: Renders a dark-themed matplotlib PNG dashboard showing fatigue timelines, incident triggers, and speed correlations.

## Getting Started

### 1. Installation

Ensure you have Python 3.8+ installed. Install the necessary packages:

```bash
pip install opencv-python mediapipe ultralytics pandas numpy matplotlib
```

### 2. Execution

To process an input video:

```bash
python Task157_DriverDrowsinessAndDistractionDetection/Code/detect.py --video <path_to_video>
```

To run using a connected webcam or live camera stream (e.g. index 0):

```bash
python Task157_DriverDrowsinessAndDistractionDetection/Code/detect.py --video 0
```

### 3. Customize Thresholds

You can tune the sensitivity of the alerts via CLI flags:

```bash
python Task157_DriverDrowsinessAndDistractionDetection/Code/detect.py --video input.mp4 --ear_threshold 0.20 --mar_threshold 0.60 --head_tilt_threshold 15.0
```

For a full list of configuration options, run:

```bash
python Task157_DriverDrowsinessAndDistractionDetection/Code/detect.py --help
```
