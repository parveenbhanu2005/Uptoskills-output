# Task 185 — Unattended Luggage & Abandoned Object Detection

**Task:** AI-Based Crowd Surveillance System

**Objective:** Detect stationary bags, backpacks, and unattended
items separated from their owners in transit hubs.

## Tools Used
- YOLOv8 / YOLOv11
- ByteTrack
- OpenCV
- Python

## Output
- Annotated video with bounding boxes and countdown timers
- CSV report with timestamps and confidence scores
- Alert when object is abandoned beyond safe time threshold
